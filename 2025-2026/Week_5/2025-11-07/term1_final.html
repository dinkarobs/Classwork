Software Development Life Cycle Phases

Phase Description
Idea phase The Phase where the software is thought of/ made
Analysis phase The phase where they analyze what they have to make the software fit the users requirements
Design The design is made to fit how the client wants it
Deployment The software is given to the client/clients
Coding Where the actual coding is done
maintenance Where the bugs & kinks get fixed
Retirement The end of expanding the software
