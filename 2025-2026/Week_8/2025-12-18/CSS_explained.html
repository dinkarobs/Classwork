CSS Vocab

Display alters an element on a web page & determines the type of box used and its position, None hides the element, Inline shows an element as an inline element, block shows an element as a block element, Flex shows an element block level flex container, Grid shows an element as a block-level grid container Css attribute:display values: box, inline, flex, grid, none
Changes font size CSS attribute:font-size
vh:viewport height, 1 vh equals 1% of the height of the viewport, vw:viewport width 1vw equals 1% of the width of the viewport, vmax: 1vmax equals 1% of the larger value between the viewport width or height, vmin: 1 vmin equals 1% of the smaller value between the viewport width or height CSS size viewport relative units: vh, vw, vmax, vmin
Absolute units do not change when the screen size changes, and are not recommended for websites, but can be used if the output medium is known such as for print layout CSS absolute units
Shows or hides an element without changing the space the element takes up. This is different from display:none; which removes the height CSS visibility
The font family attribute allows the user to change their font to the users liking, like "calibri", or "comic sans" CSS attribute: font-family
With CSS you have full control over the padding. There are properties for setting the padding for each side of an element, adds space in between the border & content CSS padding
The CSS margin is property used to create space around elements, outside of any defined borders CSS margin

CSS selectors are used to "find" (or select) the HTML elements you want to style. A CSS class selector is used to select and apply a set of styling rules to one or more HTML elements A CSS Id selector is a targeting mechanism used to apply specific styles to a single unique element within an html document

Grabs html elements matched by the second selector.
