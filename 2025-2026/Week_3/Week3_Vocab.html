Week 3 Vocabulary

Peripheral An external device that connects to a computer to expand its capabilities
Integer A whole number
Separation of Concern Something that allows us to organize code
Structural Layout The separation of content and styles / visuals making code easier to read
Float A data type that represents factional numbers
Debugging Debugging is the process of finding, analyzing and fixing any errors
None of the null Basic python type that acts as a placeholder or a default value
Variable A labeled box that can store information
Edit shortcut Keyboard hotkey that helps write code faster in a command editor
CPU Central processing unit, basically the brain of the computer
Bool Short for boolean, which means two values..."true" or "false"
Branching When your code element changes but doesn't go into a category
Form a form is a user interface element, typically an HTML "< form >" element, that allows users to input and submit data to a server for processing, storage, or to trigger an action/(looked up)
Byte LEDs A byte is a unit of digital information consisting of 8 bits. Each of these 8 bits is connected to the input of a single LED/(looked up)
String A string is a data type found in computer programming that consists of alphanumeric characters (letters and numbers)/(looked up)
